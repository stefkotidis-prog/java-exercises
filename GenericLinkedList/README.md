# Generic Linked List

A custom, immutable singly linked list implemented from scratch in Java. Demonstrates Generics (`<E>`), recursive traversal, and basic data structure operations.

## Core Concepts

* Java Generics (`<E>`)
* Recursion (`toString`, `size`, `contains`, `get`)
* Immutable node chaining (`add`, `reverse`)
