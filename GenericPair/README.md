# Generic Pair

A Java exercise demonstrating multi-type Generics (`Pair<E1, E2>`) with immutable fields, type-safe swapping, and value equality.

## Core Concepts

* Multi-type Java Generics (`<E1, E2>`)
* Java 17 `record` types
* `swap()` returning `Pair<E2, E1>`
* `equals()`, `hashCode()`, and `toString()`
